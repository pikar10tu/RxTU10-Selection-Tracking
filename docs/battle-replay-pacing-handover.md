## ลำดับที่ควรเทส (เรียงตาม "ตรวจน้อยสุด × มีโอกาสพังสุด")

### 1. เลือก preset ภาพ — คำถาม "แลคมั้ย"

Admin → ห้องแล็บจังหวะไฟต์ → ตั้งจังหวะไว้ **"กลาง"** ก่อน แล้วไล่ภาพ **สวยสุด → กลาง → เบา**
ยิงไฟต์ทดสอบ **3 ครั้งต่อ preset** จดตัวเลขในหน้าสรุป

**ดูที่ "ต่ำกว่า 30fps กี่เฟรม" เป็นหลัก** — เลือก preset ที่สวยที่สุดที่ยังได้ **0**

> มาตรวัดจะจูนศูนย์จากคาบเฟรมจริงของจอเครื่องคุณในช่วง READY?/GO! (~30 เฟรมแรก)
> แล้วนับ "สะดุด" ที่ 1.5 เท่าของคาบนั้น — ใช้ได้ทั้งจอ 60Hz และ 120Hz ProMotion
> ตัวเลขจะ**หยุดนิ่งทันทีที่ไฟต์จบ** ถ้าเห็นมันขยับขณะอ่าน แปลว่ามีบั๊ก

### 2. จ้องเฟรมตอนหมัดหนักลง — จุดแพงสุดของทั้งฟีเจอร์

จังหวะที่เลขเด้งเป็นสีทอง เฟรมเดียวนั้นมีทั้ง จอสั่น + การ์ดผู้ตีพุ่ง + การ์ดเป้าบีบตัว + หลอดเลือดหด + หลอดผีไล่ตาม ซ้อนกันหมด
**ถ้า "สวยสุด" จะกระตุกที่ไหน มันจะกระตุกตรงนี้**

### 3. กดพัก แล้วกดเล่นทันทีระหว่างหมัดยาว

แตะ **พัก** กลางหมัดน็อก แล้วแตะ **เล่น** ทันที
❌ ถ้าเห็นหมัดเดิมเล่นซ้ำสองรอบซ้อนกัน หรือมีหมัดหายไป = บั๊ก (แก้ไปแล้ว แต่นี่คือทางที่ผู้เล่นจริงจะเจอ)

### 4. กดค้างเร่งยาวๆ แล้วปล่อยกลางคัน

- ปล่อยนิ้ว → ต้องกลับความเร็วปกติทันที
- **กดค้างต่อไปตอนถึงหมัดคริ/หมัดน็อก → ต้องยังเล่นเต็มความยาว ไม่ถูกย่อ**
  (นี่คือกติกาที่ทำให้มันไม่ใช่ปุ่มข้ามที่ปลอมตัวมา)
- แตะสั้นๆ ไม่ค้าง → ขึ้นคำใบ้ "กดค้างเพื่อเร่ง" แล้วหายเอง

### 5. วงแหวนทองตอนเงื้อ ตลอดช่วงหมัดถากรัวๆ

❌ ถ้าเห็นวงแหวนทองค้างสว่างบนการ์ดที่ไม่ได้ตี (หรือการ์ดที่ตายไปแล้ว) = บั๊ก
วงแหวนนี้คือหัวใจของความลุ้นทั้งงาน ถ้ามันติดตลอดเวลามันก็ไม่ได้บอกอะไรเลย

### 6. ปล่อยให้ไฟต์จบโดยมีตัวรอดเลือดต่ำกว่า 25%

แล้วนั่งดูหน้าสรุปกับกด "ดูสนาม"
❌ ถ้ายังเห็นวงแหวนแดงเต้นอยู่ = อนิเมชันวนไม่รู้จบที่ควรหยุดไปแล้ว

### 7. ยิงไฟต์ 2–3 ครั้งติดโดยไม่ออกจากหน้า

เส้นทางที่ FX layer ต้อง re-attach และอ่าน preset ใหม่ — เคยมีบั๊ก "FX หายไฟต์ที่ 2+" มาก่อน

### 8. เปิด Reduce Motion ใน iOS Settings แล้วยิง 1 ครั้ง

(Settings → Accessibility → Motion → Reduce Motion)
- ✅ ต้องยัง: หมัดถากผ่านเร็ว · คริเงื้อนาน เลขใหญ่ · หมัดสุดท้ายช้าลงมีจังหวะนิ่ง · วงแหวนเงื้อยังขึ้น · **หลอดผียังไล่ตาม**
- ✅ ต้องหาย: จอสั่น · การ์ดพุ่ง/บีบ/หมุนกระเด็น · ดาวคอมิก

### 9. เลือกจังหวะ — คำถาม "สนุกมั้ย"

ล็อก preset ภาพที่เลือกจากข้อ 1 ไว้ แล้วไล่จังหวะ **อลังการ / กลาง / กระชับ** (×1.25 / ×1.0 / ×0.8)
อันนี้ไม่เกี่ยวกับความลื่นเลย ตัดสินด้วยความรู้สึกล้วนๆ

### 10. เทสในของจริง

หอคอย 1 ชั้น + สนามประลอง 1 ครั้ง — ต้องเล่นจบ เปิดหน้าสรุป และชั้น/ผลขยับถูกต้อง

# รอบที่ 2 (24 ส.ค.) — ท่าชน 4 แบบให้เลือก

**เสียงจากการเทสจอจริงรอบแรก: "ตัวไม่พุ่งชนเลย"**

สาเหตุที่เจอจากการไล่โค้ด (ยังไม่ยืนยันด้วยตาบนเครื่องจริง — คุณเป็นคนยืนยัน):

1. **55% ของหมัดทั้งไฟต์เป็นชั้น "ถาก" ซึ่งการ์ดไม่ขยับเลยสักพิกเซล** มีแค่ประกายเล็กวิ่งไป 70% ของทาง
   → เกินครึ่งไฟต์คือการ์ดนิ่งสนิท + ตัวเลขลอย
2. **ชั้นที่พุ่งจริง พุ่งไป "ทับกลางการ์ดเป้า"** — ตอนปะทะเลยเห็นการ์ดเดียวซ้อนกัน ไม่ใช่สองใบชนกัน
   แล้วลอยกลับที่เดิมยาว 730ms ซึ่งอ่านเป็น "ลอยกลับ" ไม่ใช่ "เด้งกลับ"
3. **การ์ดเป้าไม่ถอยหลังเลย** มีแค่บีบตัวอยู่กับที่ → ครึ่งหนึ่งของคำว่า "ชน" หายไป
4. **ถ้าเครื่องเปิด Reduce Motion อยู่ ระบบตัดการ์ดพุ่ง/จอสั่น/ดาว/น็อกทิ้งทั้งหมด**
   → หน้าตาจะตรงกับคำว่า "ไม่พุ่งชนเลย" เป๊ะๆ **เช็คข้อนี้ก่อนข้ออื่น**

## วิธีเทส

Admin → ห้องแล็บจังหวะไฟต์ → มีแถวใหม่ **"ท่าชน"** เพิ่มมา

0. ถ้ามีกล่องเหลืองเตือน **Reduce Motion** โผล่ขึ้นมา = เจอต้นเหตุแล้ว ติ๊กช่องในกล่องนั้นก่อนค่อยเทสต่อ
1. ล็อก **ภาพ = สวยสุด · จังหวะ = กลาง** ไว้
2. ยิงไฟต์ทีละแบบ **A → B → C → D** (ป้ายบนจอบอกว่ากำลังดูแบบไหนอยู่ ไม่ต้องจำ)
3. ดูสองเรื่องแยกกัน: **"อ่านออกมั้ยว่าใครชนใคร"** กับ **"ต่ำกว่า 30fps กี่เฟรม"** ในหน้าสรุป
4. บอกกลับมาว่าชอบแบบไหน + ตัวเลขสะดุดของแบบนั้น

| แบบ | ต่างตรงไหน | ชั้นถากขยับมั้ย |
|---|---|---|
| **A · เดิม** | ของที่ deploy อยู่ตอนนี้เป๊ะ (ไว้เทียบ) | ไม่ |
| **B · ชนแล้วเด้ง** | หยุดตรงจุดปะทะ เห็นการ์ดทั้งคู่ · เป้าถอยหลัง · ดีดกลับใน 220ms | ขยับ |
| **C · กระแทกหนัก** | เงื้อลึกกว่า เอียงตัวเข้าชน เป้ากระเด็นไกลสุด — อลังการสุด **แพงสุด** | ขยับ |
| **D · เร็ว สะบัด** | เงื้อสั้น แตะแล้วดีดกลับใน 130ms เหลือช่วงนิ่งให้อ่านเลข | ขยับ |

**ถ้าเจอกระตุก ตัวต้องสงสัยอันดับ 1 คือ "ชั้นถากขยับการ์ด"** (55% ของหมัด) — แบบ A ไม่มีตัวนี้
ถ้าชอบ B/C/D แต่แลค บอกมาได้ ทำแบบผสม (ท่าชนใหม่ แต่ชั้นถากนิ่งเหมือนเดิม) ให้ได้

## หลังเลือกได้

ฮาร์ดโค้ดที่ `DEFAULT_PREFS` ใน `src/utils/battleReplayPrefs.js` (มีทั้ง `fx` `pace` `style` ในนั้น)
ตอนนี้ default ยังเป็น **A** = นักศึกษายังเห็นของเดิมทุกอย่างจนกว่าจะเลือก
