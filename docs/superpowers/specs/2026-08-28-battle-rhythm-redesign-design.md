## §1 โครงสร้าง beat ใหม่ (`battleBeats.js` เขียนใหม่)

### 1.1 ฟิลด์ที่ beat ต้องมี

| ฟิลด์ | ค่า | คุม | ไม่คุม |
|---|---|---|---|
| `kind` | `hit` \| `ko` \| `finish` \| `sub` \| `skill` \| `skillMoment` \| `openGroup` | **เวลาอย่างเดียว** | ความดัง |
| `weight` | `0.0`–`1.0` ต่อเนื่อง | **ความดังอย่างเดียว** | เวลา |

### 1.2 สูตร weight (แก้ที่เดียว)

```js
export const WEIGHT_CFG = { dmgFull: 0.30, dmgWeight: 0.70, crit: 0.18, super: 0.12 }

function weightOf(e, dmgPct) {
  const w = Math.min(1, dmgPct / WEIGHT_CFG.dmgFull) * WEIGHT_CFG.dmgWeight
    + (e.crit ? WEIGHT_CFG.crit : 0)
    + (e.eff === 'super' ? WEIGHT_CFG.super : 0)
  return Math.max(0, Math.min(1, w))
}
```

**ดาเมจเท่ากัน → weight เท่ากัน → เล่าเหมือนกันเป๊ะ ทุกครั้ง ทุกไฟต์**

### 1.3 ตารางเวลา (ค่าที่ user จะไปจูนต่อ — แก้ที่นี่ที่เดียว)

```js
export const BEAT = 520          // user เลือกเอง 28 ส.ค. หลังเล่นห้องเทียบ
export const KO_MULT = 2
export const FINISH_MULT = 4
export const SKILL_PAUSE = 200   // หยุดตอนสกิลโปรกครั้งแรก
export const OPEN_GROUP_MS = 1100

/** สัดส่วนเฟส: [windup, motion, hitstop, tail] รวมเป็น 1 เสมอ */
export const SHAPE = {
  hit:    [0.28, 0.22, 0.08, 0.42],
  ko:     [0.24, 0.16, 0.18, 0.42],   // hitstop ยาว = ค้างให้เห็นจังหวะน็อก
  finish: [0.26, 0.14, 0.20, 0.40],
}
```

| kind | รวม | windup | motion | hitstop | tail | เกิด/ไฟต์ |
|---|---|---|---|---|---|---|
| `hit` | 520 | 146 | 114 | 42 | 218 | 33.9 |
| `ko` | 1040 | 250 | 166 | 187 | 437 | 4.1 |
| `finish` | 2080 | 541 | 291 | 416 | 832 | 1 |
| `sub` | **0** | — | — | — | — | 11.5 |

### 1.4 กดค้างเร่ง

```js
export const FF_SCALE = { hit: 0.45, ko: 1, finish: 1, skill: 1, skillMoment: 1, openGroup: 1 }
```

⚠️ `ko`/`finish`/`skillMoment` ห้ามย่อ — ไม่งั้นกลายเป็นปุ่มข้าม (กฎเดิมจากสเปก 23 ส.ค.)

### 1.5 ที่ถูกลบทิ้ง

`TIER_TIMING` · `HEAVY_SHARE` · `SOLID_SHARE` · `HEAVY_MIN/MAX` · `SOLID_MIN/MAX`
`scoreOf()` · `HEAVY_SCORE_FLOOR` · `PASSIVE_TIMING.glance` · `PASSIVE_SPOT_QUOTA` · pass 2 และ pass 2b ทั้งก้อน

## §2 การ์ดขยับ (`battleMotion.js`)

### 2.1 ท่าเดียว ทุกหมัด

```js
export const LUNGE = { reach: 0.72, pullBase: 8, pullPerWeight: 10, scaleBase: 0.06, scalePerWeight: 0.06 }
```

- `reach 0.72` = หยุดตรงจุดปะทะ เห็นทั้งสองใบ ไม่ทับกัน
- `weight` ปรับ **ความลึกของท่า** เท่านั้น: `pull = 8 + weight*10` (8–18px) · `scale = 1 ∓ (0.06 + weight*0.06)`
- **ระยะและเวลาคงที่ทุกหมัด** — นี่คือข้อที่ user ขอตรง ๆ
- `ko`/`finish` คูณความลึกด้วย `1.15` / `1.35` (ไม่แตะ reach)

### 2.2 การ์ดเป้า

squash **ทุกหมัด** (เดิม solid ไม่มีปฏิกิริยาเลย) แรงตาม `weight`

### 2.3 จอสั่น

| kind | สั่น |
|---|---|
| `hit` · `sub` | **ไม่สั่น** |
| `ko` | 4px × 2 |
| `finish` | 7px × 3 |

`applyImpact()` เปลี่ยนจาก if/else chain เป็น `switch (beat.kind)` **ที่มี `default` ปลอดภัย**
⇒ บั๊ก 1 หายโดยโครงสร้าง ไม่ใช่โดยการเติมเงื่อนไข

### 2.4 `MOTION_STYLES` A/B/C/D

ยุบเหลือชุดเดียว — เก็บไฟล์ไว้รอบนี้เพื่อสลับกลับ (§6) แล้วลบทิ้งหลัง user เทสผ่าน

## §4 ประกาศสกิล — "หยุดที่เหตุ ปล่อยผลไหลตาม"

### 4.1 จังหวะที่ user ออกแบบเอง

```
   0ms  ป้ายชื่อสกิลเด้งขึ้นบนการ์ด (fade in 110ms)   ◀ ไฟต์หยุด
 200ms  ★ ไฟต์เดินต่อทันที — beat ถัดไปเริ่มเงื้อ
        │ ป้ายเริ่มเลือน (300ms)                    ┐
        │ ผลของสกิลลง: เลข +N / ประกาย (500ms)       ├ วิ่งทับ beat ถัดไป
 320ms  │ หมัดถัดไปกระทบ — เลขดาเมจขึ้น              ┘
 500ms  ป้ายกับผลจางหมดพอดี
```

**ตัวที่ทำให้ไหลได้คือ "ไม่ `await` ตอน fade"** — พอครบ `SKILL_PAUSE` สั่ง `chipOut()` + `skillEffect()`
แล้ว return ทันที ไฟต์เดินต่อโดยที่ทั้งสองอย่างยังวิ่งอยู่

### 4.2 สามระดับ ตัดสินจากผลที่เกิดจริง (ไม่มีโควตา)

| kind | เงื่อนไข | เวลา | หน้าตา | เกิด/ไฟต์ |
|---|---|---|---|---|
| `skillMoment` | `revive` \| `cheatDeath` \| `saveAlly` เท่านั้น | `BEAT × KO_MULT` = 1040ms | หรี่ฉาก + แบนเนอร์ + ผลลงทีหลัง (แบบ spotlight เดิม) | **1.17**\* สูงสุด 2 |
| `skill` | ครั้งแรกของ `uid:effect` นั้นในไฟต์ | `SKILL_PAUSE` = 200ms | ชิปชื่อสกิลเกาะบนการ์ด + ผลไหลตาม | 4.39 |
| — | ครั้งซ้ำ | **0ms** | ผลอย่างเดียว ไม่มีชิป | 17.25 |
| `openGroup` | aura + onStart ก่อนหมัดแรก | `OPEN_GROUP_MS` = 1100ms (ตัวท้ายกลุ่มถือคนเดียว) | ชิปขึ้นพร้อมกันทุกใบ แล้วจางพร้อมกัน | 2.5 |

### 4.3 ทำไมหยุดเฉพาะครั้งแรก

| หยุด 200ms ตอน… | ครั้ง/ไฟต์ | เวลาที่เสีย | ผล |
|---|---|---|---|
| **ครั้งแรกของสกิลนั้น** ← ที่เลือก | 4.39 | **0.88s** | ทุกสกิลได้ประกาศ 1 ครั้ง |
| ทุกครั้งที่สกิลทำงาน | 21.64 | 4.33s | ป้าย "ลมปราณฟื้นฟู" ขึ้นซ้ำ 12.65 รอบ |
| ระบบเดิม (โควตา 3) | 3.00 | 3.60s | `execute` ไม่เคยถูกประกาศเลย |

\* วัดจากทีมที่ยัด phoenix + genie + cat ครบ (เคสหนักสุด) — ทีมทั่วไปเป็น 0 บ่อยกว่า

โควตาถูกลบได้เพราะ `skillMoment` เกิดจาก "เกือบตายแล้วรอด" ซึ่งหายากอยู่แล้วโดยธรรมชาติ
แม้ยัดสกิลกันตายครบทั้ง 3 ตัวก็ยังได้แค่ 1.17 ครั้ง/ไฟต์

### 4.4 ชิปแทนป้ายลอย

ป้ายลอย (`fx.banner`) ใช้พูล 2 ช่อง → ถูกยึดไปโผล่ผิดการ์ด (บั๊ก 4 เวอร์ชันสกิล)
**ชิปที่เกาะการ์ด** ไม่มีพูลให้ยึด ไม่มีป้ายข้ามจอ และผูกกับ "ใครใช้" ชัดกว่า
⇒ `fx.banner()` เหลือใช้เฉพาะ `skillMoment` (พูล 2 ช่องพอ เพราะเกิดสูงสุด 2 ครั้ง/ไฟต์)

## §5 ป้ายสถานะบนการ์ด (ของใหม่ — user ขอ 28 ส.ค.)

> "อยากให้มีสัญลักษณ์เป็นอีโมจิเล็ก ๆ ด้วยว่าได้รับบัฟ เช่นคุณวาฬแจกเลือดทุกตัว"
> "ปรับสัญลักษณ์บัฟให้เหมาะกับสกิล ไม่จำเป็นต้องหน้าตาเหมือนเจ้าของสกิล"

### 5.1 นิยาม

**ป้าย = "สถานะที่ติดอยู่บนการ์ดใบนี้ตอนนี้"** ไม่ว่ามาจากใคร
⇒ ป้ายไปอยู่ที่ **ปลายทางของผล ไม่ใช่ที่เจ้าของสกิล** (นกฮูกอยู่ทีมศัตรู แต่ 🎯 โผล่บนทีมเรา)

### 5.2 ตำแหน่ง 3 โซนบนการ์ด

| โซน | ของ | สถานะ |
|---|---|---|

## §6 ของเดิมสลับกลับได้ 1 รอบ

```js
// battleReplayPrefs.js
export const DEFAULT_PREFS = { fx: 'high', pace: 'normal', legacyBeats: false }
```

- เก็บใน **localStorage ของเครื่องนั้น** ไม่แตะ `config/app` ⇒ user ทดสอบไม่กระทบนักศึกษาที่กำลังเล่นอยู่
- ห้องแล็บ `?fps=1` มีปุ่ม **"จังหวะเดิม (4 ชั้น)"**
- **ค่าเริ่มต้นที่ส่งถึงทุกคน = แบบใหม่**
- ลบทิ้งพร้อม `MOTION_STYLES` A/B/C/D หลัง user เทสจอจริงผ่าน

### ขอบเขตของโหมดเดิม (ระบุให้ชัด กันตีความผิด)

| กู้กลับ | ไม่กู้กลับ |
|---|---|
| ตารางเวลา 4 ชั้น (320/600/1300/2000) | บั๊ก 1 — หมัดลูกยิงจอสั่นเต็มสูตร |
| ความดัง FX ตามชั้น (34/66/92 + shake) | บั๊ก 4 — สุ่มเยื้อง ±14px และพูลถูกยึด |

## §7 ผลรวมต่อความยาวไฟต์

ทีมที่ใช้วัด (dragon/cerberus/rabbit/fox vs wolf/shark/owl/panda — ไม่มีสกิลกันตาย):

| | หมัด | สกิล | รวม |
|---|---|---|---|
| ปัจจุบัน | 19.45s | 5.05s | **24.5s** |
