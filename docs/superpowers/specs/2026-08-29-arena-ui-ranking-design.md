## 1. โครงหน้าใหม่ — 4 โซนคนละน้ำหนัก

| ลำดับ | โซน | รูปลักษณ์ | เหตุผล |
|---|---|---|---|
| 1 | แผงสถานะของเรา | พื้นไล่สีเข้ม ตัวอักษรขาว | มีใบเดียวในหน้า = เด่นสุดโดยอัตโนมัติ |
| 2 | เลือกคู่ต่อสู้ | หัวโซน + การ์ดขาวขอบเข้ม (คงของเดิม) | เป็นของ "กดได้" หน้าตาเดียวในหน้า |
| 3 | อันดับในรุ่น | กล่องเดียว แถวบางๆ ไม่มีขอบรายแถว | ข้อมูลอ่าน ต้องเบากว่าโซนกด |

### 1.1 แผงสถานะ (`components/battle/ArenaStatus.vue` — ใหม่)

พื้นไล่สีเข้มตระกูลเดียวกับ `.tower-arena` ใน `style.css`
(`linear-gradient(160deg,#4338ca,#4f46e5,#6366f1)` + ลาย `::before` opacity .06)
เพื่อให้อ่านเป็น "พี่น้องกับหอคอย" ไม่ใช่ของแปลกปลอม

เนื้อใน เรียงจากบนลงล่าง:

- **บรรทัดหลัก:** `1012` ตัวใหญ่ + คำว่า "แต้มประลอง" + ป้าย `อันดับ 7 จาก 31`
  - ยังไม่ติดอันดับ → ป้ายเป็น `ยังไม่ติดอันดับ`
- **บรรทัดรอง:** `ชนะ 12 · แพ้ 8` + ป้ายเล็ก `ซีซั่น ส.ค.`
  - ป้ายซีซั่นเป็นของใหม่ — ตอนนี้ `applySeasonReset` บีบเรตและล้างชนะ/แพ้ทุกต้นเดือน**อย่างเงียบๆ**
    ผู้เล่นเห็นสถิติหายโดยไม่มีคำอธิบาย
  - ชื่อเดือนไทยย่อจาก `currentSeasonId()` (รูป `'YYYY-MM'`)
- **โควตา:** จุด `●●●○○` (ทึบ = ยังบุกได้) + ข้อความ `บุกได้อีก 3 ครั้งวันนี้`
  - จำนวนจุดคงที่ = `PVP_DAILY_ATTACKS` (5) · จุดที่ใช้ไปแล้วเป็นวงกลมโปร่ง
- **เส้นคั่นจางๆ**
- **ทีมเฝ้าบ้าน:** `PetThumb` ของ `activePets` (สูงสุด `BATTLE_SLOTS`) + ปุ่ม `🛡️ จัดทีม`
  - ยังไม่จัดทีม → *"ยังไม่ได้ตั้งทีมเฝ้าบ้าน — ตอนนี้ยังไม่มีใครบุกเราได้"* + ปุ่มจัดทีมเด่นขึ้น
  - ⚠️ ข้อความนี้ตรงตามโค้ดจริง: `rosterOpponents()` ข้ามแถวที่ `tm` ว่าง
    ⇒ ไม่จัดทีม = ไม่โผล่บนกระดานของใครเลย **ห้ามเขียนว่า "จะโดนบุกแล้วแพ้ฟรี"** เพราะไม่จริง

### 1.2 การ์ดคู่ต่อสู้ (แก้ในที่ ไม่ย้ายไฟล์)

คงโครงเดิม (ชื่อ · เรต · เหรียญที่จะได้ · ทีม · ปุ่มบุก) เพิ่มอย่างเดียวคือ
**ป้ายอันดับข้างชื่อคนจริง** — `🥇🥈🥉` สำหรับอันดับ 1–3 หรือ `#7` สำหรับที่เหลือ
เอาจากผลลัพธ์ `arenaRanking()` ก้อนเดียวกับกระดาน ไม่คำนวณซ้ำ
บอทไม่มีอันดับ (ไม่มีแถวใน roster) → ไม่ขึ้นป้าย
คนจริงที่ยังไม่ติดอันดับ (เพิ่งจัดทีมแต่ยังไม่เคยบุก) → ไม่ขึ้นป้ายเช่นกัน

หัวโซน `⚔️ เลือกคู่ต่อสู้` วางคู่กับปุ่ม `🔄 เปลี่ยนคู่` ส่วนข้อความ "ตีเสร็จได้คู่ใหม่ทันที"
ย้ายลงเป็นบรรทัดคำอธิบายใต้หัวโซน

## 2. ข้อมูล — เติม `pw`/`pl` ลงแถว roster

`buildRosterRow()` (`utils/roster.js`) ปัจจุบันเก็บของ PvP แค่ `r` (เรตซีซั่นปัจจุบัน)
⇒ แยกไม่ออกว่าใคร "เคยลงสนาม" กับใคร "เป็นค่าเริ่มต้น 1000"

เพิ่ม 2 ฟิลด์:

```js
const pvp = applySeasonReset(d.pvp, currentSeasonId())   // ← ก้อนเดียวกับที่คำนวณ r อยู่แล้ว
// ...
r:  num(pvp.rating, PVP_RATING_START),
...(num(pvp.wins, 0)   ? { pw: num(pvp.wins, 0) }   : {}),
...(num(pvp.losses, 0) ? { pl: num(pvp.losses, 0) } : {}),
```

- **ต้องใช้ `pvp` ก้อนเดียวกับ `r`** — ถ้าคำนวณแยก ชนะ/แพ้จะเป็นของเดือนก่อนขณะที่เรตเป็นของเดือนนี้
- **ใส่เฉพาะเมื่อ > 0** ตามแพทเทิร์นเดิมของ `m` / `ta4` / `ta15` (กันแถวบวมด้วยศูนย์ — ทุกคนทั้งรุ่นโหลด doc นี้ทุกเซสชัน)
- **ตำแหน่ง: ต่อจาก `ta15` แต่ก่อน `h` และ `ev` เสมอ** — คอมเมนต์ในไฟล์ระบุว่า `h`/`ev` ต้องอยู่ท้ายสุด
  เพราะ `rosterRowChanged()` เทียบด้วย `JSON.stringify` ซึ่งไวต่อลำดับคีย์ · สลับที่ = ยิงเขียนเปล่าทุกครั้ง
- ขนาดที่เพิ่ม: ≤ ~20B/แถว × ~105 แถว ≈ 2KB จากลิมิต 1MB

**นิยาม "เคยลงสนาม":** `(row.pw || 0) + (row.pl || 0) > 0`

แถวเดิมใน `roster/current` ยังไม่มี `pw`/`pl` และจะได้ก็ต่อเมื่อเจ้าตัวทำอะไรที่ทริกเกอร์ `syncRosterRow`
⇒ **แอดมินต้องกด "🔄 สร้าง roster ใหม่" ใน AdminView 1 ครั้ง** ข้อมูลเก่าถึงขึ้นกระดานครบ

## 3. กระดานอันดับ

### 3.1 `utils/arenaRivals.js` (ใหม่, pure + `.test.js`)

โครงตาม `towerRivals.js` แต่:
- กรองด้วย **จำนวนไฟต์ > 0** แทน `towerBest >= 1`
- ค่าที่เรียงคือ **แต้ม** (มาก→น้อย) ตัวเสมอตัดด้วยชื่อเล่นเหมือนเดิม
- แถวพก `wins`/`losses` ไปด้วยเพื่อให้ UI โชว์ `12–8`

```js
export const AROUND_RADIUS = 2
export const TOP_COUNT = 10      // ← ต่างจากหอคอย (3) เพราะกระดานนี้อยู่ในหน้าที่มีที่ว่างพอ

arenaRanking(others, me) -> { top, around, all, myRank, total, chaseName, chaseGap }
// แถว = { uid, nickname, rating, wins, losses, rank, isMe }
```

- `others` = แถวจาก `rosterRows` แปลงเป็น `{ uid, nickname: r.n, rating: r.r, wins: r.pw, losses: r.pl }`
- `me` = ค่าสดจาก `useArena()` (`rating`/`wins`/`losses` ซึ่ง preview soft-reset ให้แล้ว)
  ทับแถวของตัวเองที่มาจาก roster — แถว roster ของเราอาจเก่ากว่าค่าใน memory หนึ่งไฟต์
- `me` ที่ยังไม่เคยสู้ (ไฟต์ = 0) **ไม่เข้ากระดาน** → `myRank = null`
- `chaseGap` = แต้มที่ห่างจากคนอันดับเหนือเรา (ใช้ในบรรทัด "ไล่ X อีก N แต้ม")

### 3.2 `components/battle/ArenaRankCard.vue` (ใหม่)
