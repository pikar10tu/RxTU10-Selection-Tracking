## 🔴 ข้อจำกัดโครงสร้างที่เจอแล้ว (ต้องเข้าสเปก)

1. **`petPower.js`: ธรรมดา atk10/hp50 → ตำนาน atk14/hp70 ต่างกันแค่ 40%** (จงใจ "flat กัน snowball")
   ⇒ ในสนามรบ **พาสสีฟคือความต่างเกือบทั้งหมด** · common แรงเกิน = ตู้อัพเรทไม่มีใครหมุน (ทุกคนมี common ครบจากตั๋วฟรี 50 ใบ)
   ⇒ user เลือก **ทาง ก**: เก็บกลไกใหม่ครบทุกตัว แต่ **เลข common ต้องต่ำกว่าคู่เทียบ epic/legendary เสมอ** โดยให้ sim เป็นคนบอก
2. **`petPassives.js` เก็บ `hook` 1 + `effect` 1 ต่อเพ็ท** และ `effect` ถูกใช้เป็น *กุญแจ* ทั่วระบบ (ไอคอน/ข้อความ/aura/switch เอนจิน)
   ⇒ ของใหม่มี **7 ตัวที่หลายผล** (🐍 🐦‍🔥 🐘 🦣 🦍 🐱 🐢) ⇒ ต้องรื้อเป็น `parts: [{hook, effect, value}]` = **งานรื้อโครง ไม่ใช่เติมข้อมูล**
3. **การ์ดไฟต์จำกัดป้ายสถานะ 3 ป้าย** (เดิมชนเพดานแค่ 4.7%) ⇒ ของใหม่จะชนบ่อยกว่ามาก ต้องวัดใหม่ + ขยาย/จัดลำดับป้าย
4. `public/emoji/fluent/` มีแค่ 🦁 (`1f981.svg`) ⇒ อีก 5 ตัวรัน `scripts/fetch-fluent.mjs` เพิ่ม (สคริปต์สแกนเอง)
5. **บั๊กกาชา** `ShopView.vue:108-115` — จังหวะ "ลุ้น" พื้นที่รอบลูกแก้วเป็น `.rv-ov` ผูก `@click.self="closeReveal"` ⇒ แตะพลาด = ปิดจอ ไม่เห็นผลเลย (เหรียญเสียแล้ว) = อาการที่ user เจอ
