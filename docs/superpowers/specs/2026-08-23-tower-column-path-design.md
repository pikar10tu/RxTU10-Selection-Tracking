# หอคอย: เส้นทางคอลัมน์เดียวบนโครงหอคอย (23 ส.ค. 2026)

แทนที่เส้นทางซิกแซกซ้าย-ขวาที่ทำไว้เมื่อ 22 ส.ค. (`2026-08-22-tower-vertical-path-design.md`)
ด้วย **คอลัมน์เดียวไต่ตรงขึ้นไปบนฉากหลังโครงหอคอย** — งาน UI ล้วน ไม่แตะกลไกเกม

## ที่มา

user บอกว่าหน้าหอคอย "ยังไม่ค่อยสวย" → ขอพร้อมพ์ไปหาดีไซน์จาก Google Stitch 2 รอบ

- **รอบ 1 (ทั้งหน้า):** Stitch ย่อเส้นทาง 100 ชั้นเหลือ pill 6 ก้อน ทิ้งแถวศัตรู/VS/ปุ่มสู้ทั้งหมด
  สร้าง Material 3 palette ทับสีที่ล็อกไว้ (รอดแค่ `#fdf3e7`) และใช้ Material Symbols ทั้งที่สั่งห้าม
- **รอบ 2 (เฉพาะกล่องเส้นทาง):** โครงแข็งผ่านหมด (แถว 60px, โหนด 108×44, 8% inset, 14 ชั้น)
  แต่เขียนคอมเมนต์ยอมแพ้เองสองจุด — `"we'll use a simple placeholder line block"` (เส้นเชื่อม)
  และ `"bg-white; // Simplification for demo"` (โหนดที่ผ่านแล้ว) ส่วนรูปเพื่อนเป็น `src="placeholder"`

**สรุป: Stitch ทำได้เฉพาะกล่องสี่เหลี่ยมวางเรียง** ส่วนที่เป็นเรขาคณิต (เส้นทแยงต่อจุด)
กับส่วนที่ต้องใช้ข้อมูลจริง (คลัสเตอร์เพื่อน) มันยกธงขาวทั้งสองรอบ →
เลิกใช้ แล้วเอา 2 ไอเดียที่ใช้ได้มาทำ mock เทียบ 5 แบบเองใน artifact

user เลือกแบบ **D** = ภาพหอคอยจางๆ ข้างหลัง + โหนดไต่เป็นคอลัมน์เดียว (มาจาก Stitch รอบ 1)

## สิ่งที่เปลี่ยน (`components/tower/TowerPath.vue` ไฟล์เดียว)

1. **ซิกแซก → คอลัมน์เดียว** — `.tp-row` เป็น `justify-content: center`, ทิ้งคลาส `l`/`r` และ `--tp-pad`
2. **เส้นเชื่อมทแยง → เส้นตรง** — ทิ้งทริก `linear-gradient` มุมเอียง 4 กฎ เหลือ `width: 4px` ที่ `left: 50%`
   (**ยังแบ่งสองครึ่งอยู่** ไม่ใช่เพราะเรขาคณิต แต่เพราะสองครึ่งเป็นคนละช่วงการเดินทาง = เปลี่ยนสีคนละจังหวะ)
3. **ทิ้ง `ResizeObserver` + `boxW`** — marker หาแกน X จาก `left: calc(50% - 90px)` ได้เลย
   `markerStyle` เหลือถือแค่ Y (`90px = ครึ่งโหนด 54 + ระยะห่าง 6 + ความกว้าง marker 30`)
4. **ฉากหลัง** บน `.tp-inner` (ไม่ใช่ `.tp-box` — พื้นหลังของ scroll container ไม่เลื่อนตามเนื้อหา):
   - โครงหอคอย SVG inline ไทล์ `repeat-y` สูง **120px = 2 แถวพอดี** → แนวหินตรงกับเส้นแบ่งชั้นเสมอ
   - ไล่เฉดสีโซนทั้ง 5 ยาวตลอด 6,000px (จุดหยุดตรงกับ `ZONES` ใน `data/towerFloors.js`)
5. **ขอบขาว 4px รอบโหนด** — `box-shadow: 0 0 0 4px #fff, 3px 3px 0 4px var(--ink)`
   จำเป็น ไม่ใช่ของแต่ง: พอฉากหลังมีทั้งสีและลวดลาย ขอบ ink อย่างเดียวจะกลืนกับเส้นหอคอย
6. **รางเพื่อนย้ายไปขวาโหนดตายตัว** (`left: calc(50% + 62px)`) — ตาไม่ต้องไล่หาสลับฝั่ง
7. **วงแหวนโบนัสจัดกึ่งกลาง** — ป้าย `+N/วัน` ลอยขึ้นเหนือโหนด บังเลขชั้น ~900ms (จังหวะฉลอง รับได้)

## สองอย่างที่ฉากหลังมีสีทำพัง แล้วต้องแก้ตาม

ทั้งคู่เป็นค่าที่ "ถูก" ตอนพื้นหลังเป็นสีเรียบสีเดียว และกลายเป็น "ผิด" ทันทีที่พื้นหลังไม่เรียบ:

1. **เส้นชั้นที่ยังไม่ผ่าน `#e2e8f0`** เป็นเทาเย็นที่เลือกมาคู่กับ `--bg` → จมหายบนพื้นไล่เฉด
   เปลี่ยนเป็น `rgba(36,27,51,.16)` — การ "ทำให้เข้มลง" ทำงานได้ทุกแถบสี ต่างจากการ "ทาสีเทาทับ"
2. **พื้นโหนดที่ผ่านแล้วเป็น alpha (`zoneColor + '40'`)** → สีที่มองเห็นเพี้ยนไปทีละชั้นตามฉากหลัง
   และคอนทราสต์ตัวเลขตก เปลี่ยนเป็นผสมขาว 25% แบบ**ทึบ** คำนวณใน `tint()`

## ที่ไม่ได้ทำ (ตั้งใจ)

- **ไม่แตะ state machine ของอนิเมชันไต่** (`climbing`/`popFloor`/`fillFloor`/`snap`/`burstFloor`)
  รีวิวรอบก่อนแนะนำให้แยกเป็น `useClimbSequence()` แต่บอกไว้ว่าให้รอ P3 — งานนี้เป็น layout
  ไม่ใช่ state ถ้าแยกไปด้วยจะกลายเป็นสองการเปลี่ยนแปลงปนกันในไฟล์เดียว รีวิวยาก
- **ไม่ใช้ภาพจาก Stitch** — เป็น URL `googleusercontent` ที่เราไม่ได้เป็นเจ้าของ, เป็นภาพเรนเดอร์
  กึ่งสมจริงซึ่งตีกับไอคอน Fluent แบนทั้งหน้า, และ `bg-cover` ของมันใช้ได้เพราะเรนเดอร์แค่จอเดียว
  พอเอามาวางบนเส้นทางสูง 6,000px จะยืดจนเละ · SVG ที่วาดเองหนักไม่ถึง 2KB และไทล์ได้ไม่รู้จบ
- **ไม่มีอีโมจิใหม่** → ไม่ต้องรัน `scripts/fetch-fluent.mjs` รอบนี้
- **ไม่แตะ rules/schema** → ไม่ต้อง `firebase deploy`

## ยังไม่ได้ยืนยัน

`npm run build` ผ่าน · ตรวจ CSS ที่ compile แล้วว่า data URI กับ gradient รอด minifier (ถูกเขียนใหม่
แบบสมมูล: `center top`→`top`, `to top`+stops→`to bottom`+stops กลับด้าน) · ไม่มี `font-size` ต่ำกว่า `.7rem`

**แต่ยังไม่มีใครเห็นมันเรนเดอร์จริง** — ต้องเทสบนมือถือจริง โดยเฉพาะ:
- อนิเมชันไต่ครบซีเควนซ์ (โหนดเด้ง → เส้นไล่สีสองครึ่งต่อกัน → marker กระโดด → วงแหวนหมุดโบนัส)
- โหนดที่ล็อก (`opacity: .6`) ยังอ่านออกไหมบนแถบสีโซนบนสุด `#cbbfe2`
- คอลัมน์เดียว 100 ชั้นซ้ำจนน่าเบื่อหรือเปล่า — หมุดเหรียญกับรอยต่อโซนตัดความซ้ำได้พอไหม
- ชั้นที่มีเพื่อนหลายคน ป้าย `+N` ตกขอบการ์ดในจอแคบ (360px) หรือไม่
