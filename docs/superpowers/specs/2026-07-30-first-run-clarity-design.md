## 1. การ์ด "ทำอะไรต่อ" (หัวใจ)

**หลักการ: โชว์ทีละ 1 อย่าง ไม่ใช่ลิสต์** — ลิสต์คือปัญหาเดิม (9 ระบบกองกัน) การ์ดนี้บอกว่า "ตอนนี้ทำอันนี้" ทำเสร็จแล้วเลื่อนไปอันถัดไปเอง

ตรรกะทั้งหมดอยู่ใน pure util → เทสได้ · **ไม่เพิ่ม Firestore read แม้แต่ครั้งเดียว** (อ่านจาก `userData` ที่อยู่ในหน่วยความจำแล้ว)

### `nextAction(userData, ctx) → Action | null`

`ctx = { today, now }` ฉีดเข้าเพื่อเทส (แพทเทิร์นเดียวกับ `utils/dailyQuest.js` ที่รับ `today`)

`Action = { key, icon, title, sub, cta, to? , sheet? }` — `to` = route, `sheet` = เปิด bottom-sheet บน Home (ใช้กับเควส)

**กฎเรียงตามลำดับ เจอข้อแรกที่เข้าเงื่อนไข = ใช้อันนั้น · การเรียนมาก่อนเกมทุกข้อ (user เคาะ)**

| # | key | เงื่อนไข | ปลายทาง |
|---|---|---|---|
| 1 | `study-new` | `studyReviewedTotal === 0` (ยังไม่เคยทบทวนเลย) | `/study` |
| 2 | `study-due` | มีการ์ดใน `study.cards` ที่ `nextReviewDate <= now` | `/study` |
| 3 | `quiz-today` | `quizCoinDate !== today` (วันนี้ยังไม่ทำข้อสอบ) | `/quiz` |
| 4 | `quest` | `questNotClaimed(dailyQuest, today)` | `sheet: 'quest'` |
| 5 | `first-pet` | `pets.length === 0` | `/shop` |
| 6 | `team` | `pets.length > 0` และ `activePets.filter(Boolean).length < 3` | `/play/pets` |
| 7 | `farm-empty` | มีแปลงว่างในช่วงที่ปลดล็อกแล้ว — `farm.plots[i] == null` สำหรับ `i < farm.plotsUnlocked` (โครงตาม `useFarm.js:14` — `null` = ว่าง, array อาจสั้นกว่า `plotsUnlocked` ⇒ ช่องที่ยังไม่มี = ว่าง) | `/play/farm` |
| 8 | `expedition` | `expedition === null` และทีมครบ 3 | `/play/pets` |
| — | — | ไม่เข้าเงื่อนไขไหนเลย → คืน `null` = **ซ่อนการ์ด** | — |

**ไม่ใส่ "เก็บรายได้รายวัน"** เพราะ `DailyCard` อยู่ใต้กันแค่การ์ดเดียว — ซ้ำซ้อนเปล่าๆ

ข้อความใช้โทน `docs/voice-guide.md` — บอกว่าทำอะไรและได้อะไร ไม่หวือหวา
ตัวอย่าง: `study-due` → title "ทบทวน 12 ใบที่ครบกำหนด" · sub "ทบทวนตามรอบช่วยให้จำได้นานกว่าอ่านรวบ" · cta "ไปทบทวน"

### `NextActionCard.vue`

วางบน Home **ใต้ `ExamCountdown` เหนือ `ResidenceCard`** — คำตอบว่า "ทำอะไร" ต้องเป็นสิ่งแรกที่เห็น
ซ่อนตัวเองเมื่อ `nextAction` คืน `null` · ไม่ใช่ overlay → ไม่เกี่ยวกับกฎ Teleport

## 2. ทัวร์ 3 จอ (`IntroTour.vue`)

mount ใน `App.vue` ระดับ root = sibling ของ `#bottom-nav` → **ไม่ต้อง Teleport** (CLAUDE.md ข้อ 6: modal ที่ mount ระดับ root ปลอดภัยอยู่แล้ว) · วางถัดจาก `MigrationWelcome`

เปิดเมื่อล็อกอินแล้ว + ผ่าน gate แล้ว + `!seenIntro` · ปิด → `patchUser({ seenIntro: true }, { seenIntro: true })` · **มีปุ่มข้ามทุกจอ**

1. **นี่คืออะไร** — แอพเตรียมสอบของรุ่น ทบทวน/ทำข้อสอบแล้วได้เหรียญ
2. **เหรียญเอาไปทำอะไร** — พูดเป็นประโยชน์ ไม่ไล่ชื่อระบบ: อัปบ้านให้รายได้เพิ่ม · อัญเชิญเพ็ทไปสู้ · ปลูกฟาร์มขายของ
3. **เริ่มที่นี่** — ปุ่มเดียวไป `/study` + บอกว่ากด ℹ️ ได้ทุกหน้าถ้าสงสัย

ใช้ภาษาภาพเดิม (`ow-*` sticker: ขอบ ink 2px + `--pop`, ปุ่ม `:active` translate) · `seenIntro: false` ประกาศใน `data/userSchema.js` ให้ถูกแพทเทิร์น

**ข้อแลกเปลี่ยนที่ยอมรับ:** คนที่ใช้แอพอยู่แล้วจะเห็นทัวร์ 1 ครั้ง (ข้ามจบใน 1 แตะ) — ทางเลือก "บัญชีใหม่เท่านั้น" ต้องเดาจาก state ซึ่งไม่แน่นอน จึงเลือกทางง่ายกว่า
