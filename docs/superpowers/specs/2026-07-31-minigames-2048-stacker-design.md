# มินิเกม 2048 + Stacker — Design (31 ก.ค. 2026)

## เป้าหมาย

เพิ่มมินิเกม 2 ตัวลงแพลตฟอร์มที่มีอยู่ โดย**ไม่แตะเฟรมเวิร์กเดิมเลย** และให้ตรรกะเกมทั้งหมดเป็น pure function
ที่เทสด้วย `node --test` ได้ (บทเรียนจาก 3 งานล่าสุด: บั๊กที่หลุดออกไปทุกตัวอยู่ในจุดที่เทสไม่ถึง)

ที่มา: user เสนอ 5 ไอเดีย (Wordle ชื่อยา · Tic-Tac-Toe vs AI · Dino Run · Stacker · 2048) แล้วเลือก
**2 อันดับบนของตารางประเมิน = 2048 + Stacker**

**ทำไมไม่เอาอีก 3 ตัว** (บันทึกไว้กันถามซ้ำ):
- **Wordle ชื่อยา** — ตรวจข้อมูลจริงแล้ว เด็ค 78 ตัวยา **ไม่มีชื่อยาว 5 ตัวอักษรเลยสักตัว** (ความยาวกระจุกที่
  9–14 · ช่วง 6–8 มีแค่ 7 ตัว · ยาวสุด 33) ⇒ Wordle แบบตายตัวทำไม่ได้ · ไอเดียดีที่สุดในเชิงการเรียน
  แต่ผิดรูปแบบกับเด็ค — ถ้าจะเอาแนวนี้ควรเปลี่ยนเป็น "เดาชื่อยาจากคำใบ้" (รับความยาวไม่เท่ากันได้)
- **Dino Run** — ซ้ำโครงกับ Capsule Rush ที่ live อยู่แล้ว (หลบสิ่งกีดขวาง · คะแนน = ไปได้ไกลแค่ไหน)
- **Tic-Tac-Toe vs AI** — ไม่มีคะแนนตัวเลข ⇒ กระดานอันดับใช้ไม่ได้ · minimax 3×3 เล่นสมบูรณ์ = เสมอตลอด

## เฟรมเวิร์กที่มีอยู่ (ไม่แตะ)

- `src/data/minigames.js` — `MINIGAMES` registry · เพิ่ม entry = การ์ดบนหน้า Play โผล่เอง
- `src/components/minigame/MinigameShell.vue` — หัวเกม/ปุ่มกลับ/สถิติส่วนตัว/ปุ่มอันดับ + BottomSheet
- `src/components/minigame/MinigameLeaderboard.vue` + `buildMinigameBoard()` — อันดับทั้งรุ่น
- `src/utils/minigameCore.js` → `grantCoins(score, game)` → `{ coins, flagged }` (clamp ที่ `maxPlausibleScore`)
- แพทเทิร์นบันทึกผล (ลอกจาก `CapsuleRushView.vue`): `best` อ่านจาก `auth.userData?.minigames?.<key>?.best` ·
  `patchUser` optimistic + server ที่ใช้ `increment(coins)` และ dot-notation `'minigames.<key>.best'`
- route: `/play/games/<slug>` lazy import ใน `src/router/index.js`

⚠️ `CapsuleRushView.vue` hardcode `#4f46e5` ซึ่งเป็นสีธีม**เก่า** — ธีมจริงตอนนี้คือ `--primary: #6d3bf5`
(`style.css:509`) · **เกมใหม่ต้องใช้ `var(--primary)` ห้ามลอก hex เก่ามา**

## เกม 1: 2048

**กติกา (มาตรฐาน ไม่ประดิษฐ์เพิ่ม):** ตาราง 4×4 · ปัดขึ้น/ลง/ซ้าย/ขวา ไทล์เลื่อนชนขอบ · ไทล์ค่าเท่ากัน
2 ตัวที่ชนกันรวมเป็น 1 ตัวค่าคูณสอง · **ไทล์ที่รวมแล้วห้ามรวมซ้ำในตาเดียวกัน** · ทุกตาที่กระดานเปลี่ยนจริง
เกิดไทล์ใหม่ในช่องว่างสุ่ม (2 ที่ 90% · 4 ที่ 10%) · จบเกมเมื่อไม่มีตาที่ทำให้กระดานเปลี่ยนได้แล้ว

**คะแนน:** ผลรวมค่าของไทล์ที่เกิดจากการรวมทุกครั้ง (แบบต้นฉบับ) — ยิ่งเยอะยิ่งดี เข้ากับกระดานอันดับ

**อินพุต:** ปัดนิ้ว 4 ทิศบนมือถือ + ปุ่มลูกศรบนคีย์บอร์ด (เดสก์ท็อป)

**เศรษฐกิจ:** `coinPerPoint: 1` · `maxPlausibleScore: 20000`
เหตุผล: เกมที่เล่นดีจริงถึงไทล์ 1024–2048 ได้คะแนนหลักหมื่น · ตั้งเพดานต่ำกว่านี้จะ **flag คนเล่นเก่งเป็นโกง**
(`flagged` ยิง `reportCheat` เข้า admin triage — false positive แพงกว่าเงินเฟ้อเล็กน้อย) · ตัวเลขปรับได้ที่ registry

## เกม 2: Stacker

**กติกา:** บล็อกวิ่งซ้าย–ขวาเหนือกองที่ซ้อนไว้ · แตะเพื่อวาง · ส่วนที่ยื่นเกินชั้นล่างถูกตัดทิ้ง
บล็อกชั้นถัดไปกว้างเท่าส่วนที่เหลือ · จบเกมเมื่อความกว้างเหลือ 0 (วางพลาดจนหมด) · ยิ่งสูงยิ่งเร็ว

**คะแนน:** จำนวนชั้นที่วางสำเร็จ

**อินพุต:** แตะที่ไหนก็ได้ในพื้นที่เกม (มือถือเป็นหลัก)

**เศรษฐกิจ:** `coinPerPoint: 20` · `maxPlausibleScore: 60`
เหตุผล: ชั้นเป็นหน่วยหยาบ (เล่นดี ~15–25 ชั้น) ⇒ ให้ต่อชั้นสูงหน่อยจะรู้สึกคุ้ม · เพดาน 60 ชั้นสูงกว่าที่คนทำได้จริงมาก

## สถาปัตยกรรม

**ตรรกะเกมทั้งหมดเป็น pure function แยกไฟล์ เทสด้วย `node --test`** · view ทำแค่ 3 อย่าง: รับอินพุต →
เรียก pure function → เรนเดอร์ผล + ต่อกับเฟรมเวิร์ก (best/coins/leaderboard)

| `src/utils/game2048.test.js` **(ใหม่)** | เทสกติกาครบ: เลื่อน/รวม/ห้ามรวมซ้ำ/ไม่ขยับก็ไม่เกิดไทล์/จบเกม |

| `src/utils/stacker.test.js` **(ใหม่)** | เทส: ตัดส่วนยื่น/ความกว้างลด/วางตรงเป๊ะไม่เสียความกว้าง/จบเมื่อกว้าง 0 |
| `src/views/StackerView.vue` **(ใหม่)** | แถวบล็อก + แตะวาง + จบเกม + บันทึกผล |

## ความเสี่ยงที่รู้ล่วงหน้า

- **`Pill Crush` ยังค้างเป็น `status:'soon'`** ในหน้า Play · งานนี้ไม่ยุ่งกับมัน แต่พอมีเกมใหม่ 2 ตัว
  ผู้ใช้จะเห็นการ์ด "เร็วๆ นี้" ค้างอยู่นานขึ้น — **ให้ user ตัดสินภายหลังว่าจะถอด entry ออกไหม**
- 2048 ต้องกัน **ปัดนิ้วแล้วหน้าเลื่อนตาม** — พื้นที่กระดานต้อง `touch-action: none` (ลอกจาก `.cr-stage`)
- ทั้งสองเกมต้องหยุดลูป/ตัวจับเวลาใน `onBeforeUnmount` ไม่งั้นรั่วเมื่อออกจากหน้า (Capsule Rush ทำไว้แล้ว ลอกมา)
