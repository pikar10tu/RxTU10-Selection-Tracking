## A1 · จัดทีม — โมเดล "ช่องคือเคอร์เซอร์"

### ที่มา

เกมมือถือที่มีระบบจัดทีม (Epic Seven, Summoners War, Honkai Star Rail, Fire Emblem Heroes)
ใช้แก่นเดียวกันหมด: **ช่องเป็นตัวชี้เป้า ส่วนคลังไม่เคยถูกปิดการใช้งาน**
ผู้เล่นจึงไม่มีทางเจอสถานะ "กดอะไรก็ไม่ได้" และไม่ต้องจำว่าแตะตรงไหนแปลว่าอะไร

### พฤติกรรม

เพิ่ม state ตัวเดียวใน `TeamPicker.vue`: `cursor = ref(0)` (index ของช่องที่กำลังเล็ง)

| การกระทำ | ผลลัพธ์ |
|---|---|
| เปิดแผ่นจัดทีม | `cursor` = ช่องว่างช่องแรก · ถ้าเต็มทุกช่อง = ช่อง 0 |
| แตะ **ช่องทีม** | `cursor = i` เท่านั้น — **ไม่เปิดโมดัลอีกต่อไป** (แก้ปัญหา 1) |
| แตะ **การ์ดในคลัง** | ใส่ตัวนั้นลงช่อง `cursor` แล้ว `cursor` เลื่อนไปช่องว่างถัดไป (ไม่มีช่องว่าง = อยู่กับที่) |
| แตะการ์ดในคลัง **ตอนทีมเต็ม** | สลับทันที ตัวเดิมในช่อง `cursor` กลับเข้าคลัง (แก้ปัญหา 2) |
| แตะการ์ดที่ **อยู่ในทีมอยู่แล้ว** | ย้ายมาช่อง `cursor` โดยสลับที่กับตัวที่อยู่ตรงนั้น (= จัดลำดับทีม) |
| แตะปุ่ม **⋯** มุมช่อง | เปิด `PetDetailModal` (ดู / วิวัฒน์ / ถอด) — เส้นทางเดิมย้ายมาอยู่ที่นี่ |

`toggle()` เดิมถูกแทนด้วย `placeAt(cursor, id)` — ตรรกะล้วน แยกออกเป็น pure function
`src/utils/teamSlots.js` + `teamSlots.test.js` (`node --test`) เพราะเคสสลับ/ย้าย/เกินช่อง เดาด้วยตาไม่ออก

```js
// teamSlots.js — pure
export function placeAt(slots, cursor, id, maxSlots) → { slots, cursor }
```

กฎที่เทสต้องคุม:
- ใส่ลงช่องว่าง → ช่องนั้นได้ตัว, cursor ขยับไปช่องว่างถัดไป
- ใส่ทับช่องที่มีตัว → ตัวเดิมหลุดออก (ไม่ไปโผล่ช่องอื่น)
- ใส่ตัวที่อยู่ช่องอื่นอยู่แล้ว → สลับที่กัน 2 ช่อง ไม่ใช่ทำสำเนา
- ใส่ตัวที่อยู่ในช่อง cursor เอง → ไม่เปลี่ยนอะไร (idempotent)
- `slots` ยาวคงที่ = `maxSlots` เสมอ ช่องว่างเป็น `null`

### ของแถม — การจัดลำดับทีมที่หายไป

`data/guide.js` เขียนไว้เองว่า *"ตัวซ้ายสุดได้ออกตีก่อน วางตัวที่อยากให้ออกโรงก่อนไว้ซ้าย"*
แต่ `TeamPicker` วันนี้มีแต่ `cur.push(id)` ต่อท้าย — **ผู้เล่นไม่มีทางเรียงลำดับได้เลย** ไกด์จึงโกหกมาตลอด
โมเดลเคอร์เซอร์ทำให้เรียงได้ทันทีโดยไม่ต้องเพิ่ม UI ใหม่

### สถานะ "กดไม่ได้" ที่เหลือ

เหลือกรณีเดียว = เพ็ทที่ **ออกผจญภัยอยู่** (`expeditionIds`)
คงสีจาง + ป้าย 🗺️ ไว้ แต่ **ต้องกดได้** แล้วเด้ง toast บอกเหตุผล
(เดิม `:disabled` ทำให้แตะแล้วเงียบสนิท ผู้เล่นไม่รู้ว่าทำไม)

### หน้าจอ

```
┌ ⚔️ จัดทีมต่อสู้ ─────────────────────┐
│    ①          ②          ③          │
│   🐉 ⋯       🦊 ⋯      ┌ + ┐        │  ③ มีวงกะพริบ = cursor
│  บาฮามุท    จิ้งจอก     └───┘        │
│                                      │
│   กำลังเลือกให้ช่อง ③ · แตะตัวข้างล่าง │  ← แทน hint เดิม
├──────────────────────────────────────┤
│   คลัง — ทุกใบกดได้                    │
└──────────────────────────────────────┘
```

- วงเคอร์เซอร์: `outline: 3px solid var(--primary)` + `animation` เต้นเบา ๆ
  ต้องเคารพ `prefers-reduced-motion` (ตัดอนิเมชันเหลือเส้นทึบ)
- แถบสถานะเปลี่ยนข้อความตาม cursor — ห้ามใช้ hint เดิมที่บอกกฎแห้ง ๆ
- a11y: ช่อง = `role="radio"` ใน `role="radiogroup"` (`aria-checked` ตาม cursor)
  การ์ดคลัง = ปุ่มปกติ `aria-label` บอกว่า "ใส่ <ชื่อ> ลงช่อง N"

### จุดที่ห้ามพัง

- `PetsView.vue` กับ `ArenaView.vue` กับ `TowerView.vue` เรียก `<TeamPicker v-model:open>` เหมือนกันหมด — ห้ามเปลี่ยน props/emits
- `save()` ยังต้องเรียก `syncRosterRow()` ทุกครั้ง ไม่งั้นคู่ต่อสู้ใน Arena เห็นทีมเก่า
- เขียน `activePets` ผ่าน `auth.patchUser(optimistic, server)` เท่านั้น (CLAUDE.md)
- `activePets` เก็บ **species id** ไม่ใช่ instance id — อย่าเผลอเปลี่ยนตอน refactor (เคยพังมาแล้ว ดู `rxtu10_pvp_matchmaking`)

## A2 · หน้าข้อมูลเพ็ท — ยกทักษะขึ้นบน

### ลำดับใหม่ใน `PetDetailModal.vue`

```
เดิม:  ฮีโร่ → [ปุ่มใส่ทีม] → ATK/HP/รายได้ → ความหายาก/เกรด+วิวัฒน์ → ✨ทักษะเฉพาะ
ใหม่:  ฮีโร่ → ✨ทักษะเฉพาะ → [ปุ่มใส่ทีม] → ATK/HP/รายได้ → ความหายาก/เกรด+วิวัฒน์
```

การ์ดทักษะเป็นบล็อกเด่นใต้ชื่อเพ็ททันที:
- ไอคอน + ชื่อสกิล ตัวใหญ่
- คำอธิบายที่เติมเลขจริงแล้วด้วย `passiveText(pdPassive)` (มีอยู่แล้ว — **ห้ามพิมพ์ตัวเลขลง desc เอง** ตามกฎใน `petPassives.js`)
- ไม่มีทักษะ → "ตัวนี้ยังไม่มีทักษะเฉพาะ" (ข้อความเดิม)

### ป้ายสาย

ป้ายในส่วนฮีโร่เปลี่ยนจาก `EL_NAME` เฉย ๆ เป็น emoji + ชื่อสายใหม่ **สั้น ๆ แค่นั้น**
เช่น `✊ จู่โจม` — **ไม่ต้องมีคำบรรยายบุคลิกต่อท้าย** (ตัดสินใจแล้ว: ผู้ใช้ไม่เอา "โจมตีสูง เลือดน้อย")

### ไม่ทำในรอบนี้

- ไม่เพิ่มบล็อก "คู่หู" ของแมวน้ำ×วาฬ — ผู้ใช้เลือกให้ `รางวัลคนเก่ง` เป็นกิมมิคเล็ก ๆ เฉย ๆ
  (มันจะไปโผล่เองในไฟต์ผ่านชั้นป้ายผ่าน/สปอตไลต์ของสเปก C)
- ไม่ถอดปุ่ม "ใส่ในทีมต่อสู้" ที่ซ้ำกับ TeamPicker — ผู้ใช้ไม่ได้ติดใจข้อนี้

## A3 · อันดับหอคอย

### หัวข้อ

`🏁 เพื่อนร่วมไต่` → **`🏆 อันดับหอคอย`**

### `utils/towerRivals.js` — คืนหน้าต่างรอบตัวเรา

`towerRanking()` เพิ่มฟิลด์ (ของเดิมคงไว้ทั้งหมด เพราะการ์ดยังใช้ `myRank`/`total`/`chase*`):

```js
{
  top: […],          // เดิม — 3 อันดับแรก (คงไว้ ใช้ท่อนบนของการ์ด)
  around: […],       // ใหม่ — ±2 รอบตัวเรา (5 แถว) พร้อม rank จริง
  all: […],          // ใหม่ — ทุกคนเรียงแล้ว สำหรับกระดานเต็ม
  myRank, total, chaseName, chaseGap,   // เดิม
}
```

เคสขอบที่เทส (`towerRivals.test.js` — ยังไม่มี ต้องสร้าง):
- เราอยู่อันดับ 1–3 → `around` ซ้อนกับ `top` → **การ์ดต้องไม่โชว์แถวซ้ำ** (ยุบเป็นลิสต์เดียว ไม่มีตัวคั่น `⋯`)
- เราอยู่ท้ายสุด → `around` มีแค่ 3 แถว (ไม่แพดของปลอม)
- เรายังไม่ติดอันดับ (`towerBest` = 0) → `myRank: null`, `around: []` → การ์ดโชว์ `top` อย่างเดียว + ชวนเริ่มไต่ (ข้อความเดิม)
- คนเดียวในกระดาน → การ์ดซ่อนทั้งใบ (เงื่อนไขเดิมใน `TowerView.vue`)
