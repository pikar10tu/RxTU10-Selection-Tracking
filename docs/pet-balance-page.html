# บรีฟระบบเพ็ท RxTU10 — สำหรับให้ AI ช่วยเรียบเรียงพาสสีฟและ flavor text

> เอกสารนี้ให้ข้อมูลครบเพื่อให้คุณเสนอแก้ได้โดยไม่ต้องถามกลับ
> ถ้าตรงไหนข้อมูลไม่พอ ให้ระบุว่าขาดอะไร แล้วเสนอต่อไปภายใต้สมมติฐานที่เขียนกำกับไว้

## 1. บริบท

RxTU10 เป็นเว็บแอปของนักศึกษาเภสัชศาสตร์ ธรรมศาสตร์ รุ่น 10 (ผู้เล่นเป็นเพื่อนร่วมรุ่นกันทั้งหมด ประมาณ 85 คน)
แอปมีทั้งส่วนเตรียมสอบ (คลังข้อสอบ แฟลชการ์ด) และส่วนเกมสะสมที่เอาไว้ล่อให้กลับมาเปิดแอปทุกวัน
ระบบเพ็ทคือแกนของฝั่งเกม — สุ่มได้จากกาชา เอาไปไต่หอคอย สู้กันเอง (PvP) และสร้างรายได้เหรียญต่อวัน

ภาษาบนหน้าจอเป็นภาษาไทยทั้งหมด เล่นบนมือถือเป็นหลัก

## 2. กติกาการต่อสู้ (ต้องเข้าใจก่อนเสนอแก้พาสสีฟ)

- ทีมละ **3 ตัว** สู้กันอัตโนมัติ ผู้เล่นไม่ได้กดอะไรระหว่างไฟต์ — ดูอย่างเดียว (ประมาณ 20 วินาที)
- **ผลัดกันตีทีละตัว สลับฝั่งทุกหมัด** (ฝั่ง A ตี 1 หมัด → ฝั่ง B ตี 1 หมัด → A ...) ไม่ใช่ทั้งทีมตีพร้อมกัน
  ฝั่งที่มีตัวรอดมากกว่าเป็นฝ่ายเริ่ม · ในทีมไล่ตีตามลำดับช่องวนไปเรื่อยๆ
- **เลือกเป้าแบบสุ่ม** จากศัตรูที่ยังไม่ตาย (ยกเว้นพาสสีฟที่ไปเปลี่ยนเป้า)
- "รอบ" (round) นับใหม่ทุกครั้งที่วนกลับมาถึงฝั่งที่เริ่มก่อน — พาสสีฟที่ทำงาน "ต้นรอบ" จะยิงตรงนี้
- สาย (element) เป็นเป่ายิ้งฉุบ 3 สาย: **จู่โจม `fist` ชนะ สมดุล `scissors` ชนะ พิทักษ์ `paper` ชนะ จู่โจม**
  ได้เปรียบ ×1.20 · เสียเปรียบ ×0.83
- สายยังบิดสเตตัสด้วย: จู่โจม โจมตี×1.2 เลือด×0.85 · สมดุล 1.0/1.0 · พิทักษ์ โจมตี×0.85 เลือด×1.2
- คริ 12% คูณ 1.6 · ดาเมจแกว่งสุ่ม ±22% ทุกหมัด
- สเตตัสฐานตามระดับความหายาก (ก่อนคูณสายและเกรด):
  ธรรมดา atk 10 / hp 50 · หายาก 11/56 · เอพิค 13/63 · ตำนาน 14/70
  เกรด (ยังไม่อัพ → I–V) คูณ 1.0 / 1.15 / 1.32 / 1.52 / 1.74 / 2.0

## 3. กฎเหล็กของพาสสีฟ (ห้ามละเมิด)

1. **พาสสีฟห้ามเพิ่มจำนวน "จังหวะหมัด"** เพิ่มได้แค่ตัวเลขกับเอฟเฟกต์ภาพ
   เพราะทุกหมัดกินเวลาบนจอ ถ้าพาสสีฟงอกหมัดใหม่ ไฟต์จะยืดจนคนดูเบื่อ
   มีข้อยกเว้นตัวเดียวคือ `killChain` (น็อกแล้วได้ตีต่อ) ซึ่งจึงต้องมีเพดานจำนวนครั้ง
   ⇒ พาสสีฟแบบ "ตีหลายเป้า" หรือ "ตีสองที" ที่มีอยู่ ถูกยัดให้อยู่ใน **หมัดเดียวกัน** ทั้งหมด
2. **ห้ามเขียนตัวเลขลงในคำอธิบาย** ต้องใช้ตัวแปร `{pct}` `{count}` `{max}` `{below}` `{chance}` `{times}`
   แล้วระบบจะเติมเลขจริงให้เอง — ไม่งั้นพอจูนเลข คำอธิบายจะโกหกทันทีโดยไม่มีใครรู้
3. พาสสีฟทุกตัวมี **3 ขั้น** (`value` = ขั้น 1, `step` = เพิ่มต่อขั้น) ตั้งให้ขั้น 3 ราว **1.5–1.8 เท่า** ของขั้น 1
   ไม่ใช่ 3 เท่า เพราะหลายอันเป็น % ที่ชนเพดานความสมเหตุสมผล
   (ระบบอัพขั้นยังไม่เปิดในเกม แต่ตัวเลขต้องเตรียมไว้ให้ถูก · `step: 0` แปลว่าอัพขั้นแล้วค่านี้ไม่ขยับ)
4. **คีย์ข้อมูลห้ามเปลี่ยน** — `fist`/`scissors`/`paper` และ id ของเพ็ททุกตัว ถูกอ้างอิงในฐานข้อมูลของผู้เล่นจริงแล้ว
   เปลี่ยนได้เฉพาะ "คำที่ผู้เล่นเห็น" (ชื่อพาสสีฟ คำอธิบาย flavor)
5. คำที่ผู้เล่นเห็น เรียกสายว่า **"สาย"** ไม่ใช่ "ธาตุ"

## 4. โครงสร้างข้อมูลพาสสีฟ

```js
bahamut: {
  name: 'ลมหายใจราชัน',        // ชื่อพาสสีฟที่โชว์บนจอ
  icon: '🔥',                   // อีโมจิประจำพาสสีฟ (สื่อ "ผล" ไม่ใช่สื่อ "ตัวสัตว์")
  hook: 'onStart',              // ทำงานตอนไหน
  effect: 'aoeOpener',          // กลไก (ต้องเป็นชื่อที่โค้ดรู้จักเท่านั้น)
  value: { pct: 12 },           // ค่าที่ขั้น 1
  step:  { pct: 4 },            // เพิ่มต่อ 1 ขั้น
  desc:  'เริ่มสู้ สาดเปลวไฟใส่ศัตรูทุกตัว {pct}% ของพลังโจมตี',   // คำอธิบายเต็ม
  short: 'เริ่มสู้ ยิงศัตรูทุกตัว {pct}% ของพลังโจมตี',            // ฉบับสั้น ใช้บนป้ายในไฟต์
}
```

## 6. ผลวัดของพาสสีฟ (วัดจากเอนจินไฟต์ตัวจริง ไม่ใช่การประเมินด้วยสายตา)

**วิธีวัด:** เอาเพ็ทที่จะวัด + เพื่อนที่ "ไม่มีพาสสีฟ" อีก 2 ตัว ไปสู้กับทีมที่ไม่มีพาสสีฟเลย 3 ตัว
โดยตั้งสเตตัสของเพื่อนทุกตัวให้เท่ากับเพ็ทที่วัดเป๊ะ (ระดับ/สาย/เกรดเดียวกัน) รันตัวละ 1,500 ไฟต์
⇒ ส่วนต่างจาก 50% คือผลของพาสสีฟล้วนๆ = คอลัมน์ **"ผลจริง"**

คอลัมน์ **"ร่างเท่ากัน"** = จับพาสสีฟทุกตัวใส่ร่างเอพิคเหมือนกันหมด แล้วให้ปะทะกันเองครบทุกคู่ (ตัวละ 13,000 ไฟต์)
ตัดข้อได้เปรียบจากสเตตัสตามระดับออก ⇒ บอกว่า "พาสสีฟตัวไหนแรงกว่ากันจริง" · 50% คือเสมอ

**ข้อจำกัดที่ต้องรู้:** ทั้งสองตัวเลขวัดแบบ "มีพาสสีฟตัวเดียวในทีม" แต่ทีมจริงมีพาสสีฟครบทั้ง 3 ช่องเบียดกันเอง
เลขจริงในเกมจะต่ำกว่านี้ทุกตัว (ทีมจริง 3 ช่อง มีพาสสีฟครบ 3 ตัว) — ใช้เทียบ **ลำดับก่อนหลัง** ได้ ใช้เป็นค่าสัมบูรณ์ไม่ได้

### สิ่งที่ตัวเลขชี้ให้เห็น

1. **🐘 บากุ (`guardian`) ได้ −3.1%** คือทีมที่มีบากุแพ้บ่อยกว่าทีมที่ไม่มีพาสสีฟอะไรเลย
   สาเหตุ: การรับดาเมจแทนไม่ได้ *ลด* ดาเมจ แค่ *ย้าย* ไปกองที่บากุ — ตัวนี้ต้องแก้กลไก ไม่ใช่แค่ขยับเลข
2. **🦅 กริฟฟิน +0.3% · 🦈 ฉลาม +1.3% · 🦖 ทีเร็กซ์ +4.3% · 🐹 แฮมสเตอร์ +3.7%** = ติดแล้วแทบเหมือนไม่ติด
   สามตัวแรกเป็นพาสสีฟที่ออกฤทธิ์ "ตอนได้เปรียบอยู่แล้ว" (เล็งตัวใกล้ตาย / ตีตัวเลือดน้อยแรงขึ้น / แรงขึ้นหลังฆ่าได้)
   ซึ่งเกมมักตัดสินไปแล้วก่อนพาสสีฟจะมีความหมาย · 2 ตัวในนี้เป็นระดับตำนานที่คนสุ่มยาก
3. **สายฟื้นเลือดทุกต้นรอบแรงสุดในเกม** (แพนด้า +49.5 · ยูนิคอร์น +44.1 · อูโรโบรอส +39.7 · ผีเสื้อ +37.8)
   เพราะฟื้นทุกรอบมันทบต้น และยิ่งฟื้นไฟต์ยิ่งยาว ยิ่งยาวยิ่งได้ฟื้นอีก
4. **บันไดความหายากไม่ได้อยู่ที่พาสสีฟ** — พอวัดบนร่างเดียวกัน ผีเสื้อ (ธรรมดา) ได้ 52.8% แรงกว่าตำนาน 5 ตัวจาก 9 ตัว
   ระดับความหายากตอนนี้ยืนอยู่ได้ด้วยสเตตัสดิบล้วนๆ
5. **13 จาก 27 ตัวใช้กลไกซ้ำกัน** — ฟื้นตัวเอง 2 ตัว · ฟื้นเพื่อน 2 · หลบ 2 · ลดดาเมจ 2 · ตีหลายเป้า 2 · กันตาย 3
6. **`cleave` ของเซอร์เบอรัสตั้งไว้ที่ 3 เป้า ซึ่งเท่ากับทั้งทีมศัตรูพอดี** เพราะทีมมีแค่ 3 ช่อง
   ⇒ ทุกหมัดโดนครบทุกตัวเสมอ ไม่มีวันพลาด · เป็นเหตุผลที่มันขึ้นมาอันดับ 2 (64.2%) ทั้งที่เป็นแค่ระดับเอพิค
   ตัวเลข `count` ของ `cleave` ควรถูกทบทวนใหม่ทั้งคู่ (มังกร 2 เป้า = 2 ใน 3 ของทีมศัตรูแล้ว)

## 7. เรื่อง flavor text

- flavor คือข้อความ 1 บรรทัดใต้ชื่อเพ็ท มีไว้ให้ยิ้ม ไม่ได้บอกกลไก (กลไกอยู่ในคำอธิบายพาสสีฟแยกต่างหาก)
- **ปัญหาที่เห็นตอนนี้: โทนไม่สม่ำเสมอตามระดับ** — ระดับธรรมดา/หายาก/เอพิค เป็นมุกชีวิตนักศึกษาเภสัช
  ("ตุนแคปซูลเต็มแก้มเหมือนตุนชีตก่อนสอบ", "ออกฤทธิ์เร็วกว่า IV push ซะอีก")
  แต่ระดับตำนานเกือบทั้งหมดเป็นคำบรรยายเทพปกรณัมตรงๆ ("ราชาแห่งเวหา ปีกครึ่งอินทรีครึ่งสิงห์") ไม่มีมุกเลย
- ความยาวที่ใช้ได้จริงบนมือถือ: **ประมาณ 40–60 ตัวอักษร** ยาวกว่านี้การ์ดจะตัดคำ
- ห้ามอ้างอิงตัวละคร/ชื่อเฉพาะจากเกมหรือการ์ตูนที่มีลิขสิทธิ์
- ห้ามมุกที่ล้อผลการเรียนหรือความล้มเหลวของคนใดคนหนึ่งแบบเจาะจง (ผู้เล่นเป็นเพื่อนร่วมรุ่นกันจริงๆ)

## 8. โทนภาษาของแอป (ยึดตามนี้)

1. พูดกับผู้เล่นตรงๆ ว่า "คุณ" สุภาพแต่เป็นกันเอง
2. บอกก่อนว่า "นี่คืออะไร ทำอะไรได้" แล้วค่อยบอกเงื่อนไข
3. **ตัดคำโอ้อวด** — เก๋า, เทพ, สุดยอด, ปัง, อลังการ, จัดเต็ม, "ไม่มีใครรอด" ห้ามใช้
4. เลี่ยงศัพท์เกม/อังกฤษลอยๆ ที่ไม่อธิบาย
5. สั้น กระชับ หนึ่งความคิดต่อประโยค
6. flavor อบอุ่นได้ แต่ห้ามเคลมเกินจริง

ตัวอย่างที่เคยแก้: "เป็นเครื่องวัดความเก๋าของคุณ" → "เลเวลบ้านจะโชว์บนโปรไฟล์ให้เพื่อนเห็นว่าคุณเล่นมาถึงไหนแล้ว"

## 9. โจทย์ที่อยากให้ช่วย

**(ก) เรียบเรียงพาสสีฟใหม่** ให้ตอบ 3 ข้อนี้พร้อมกัน:
- ตัวที่วัดได้ว่าแทบไม่มีผล (บากุ กริฟฟิน ฉลาม ทีเร็กซ์ แฮมสเตอร์) ต้องรู้สึกได้ว่ามีตัวตน
- ระดับยิ่งหายาก พาสสีฟควรยิ่งน่าตื่นเต้น (ไม่จำเป็นต้องแรงกว่ามาก แต่ต้องไม่จืดกว่า)
- ลดความซ้ำของ 13 ตัวที่กลไกทับกัน หรือทำให้มันรู้สึกต่างกันจริง

**(ข) เขียน flavor text ใหม่** ให้โทนเป็นชุดเดียวกันทั้ง 27 ตัว

**รูปแบบคำตอบที่อยากได้:**
- ตารางเดียวเรียงตามระดับ: `id | ชื่อพาสสีฟใหม่ | hook | effect | value | step | desc | short | flavor ใหม่`
- ตัวไหนที่ `effect` เป็นกลไกใหม่ที่โค้ดยังไม่มี **ให้ทำเครื่องหมาย 🆕 ไว้ชัดๆ** พร้อมอธิบายว่าอยากให้ทำงานยังไง
  (ยังไม่ต้องเขียนโค้ด — แค่ต้องรู้ว่างานนี้ใหญ่แค่ไหน)
- ท้ายคำตอบ สรุปสั้นๆ ว่าตัวไหน "แก้เลขอย่างเดียว" ตัวไหน "ต้องเขียนโค้ดใหม่"
